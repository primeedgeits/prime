# MNVR Docs

Product ideas, product documentation and code documentation for **MNVR**, an in-vehicle video recorder for buses (surveillance, GPS tracking, CAN vehicle health, two-way TCP backend link and voice calls).

- **Website:** https://primeedgeits.github.io/prime/
- **AI index:** https://primeedgeits.github.io/prime/llms.txt lists every page as plain Markdown, for Claude and other AI assistants.

## Editing

1. Edit or add Markdown files in `docs/`.
2. For a new page, add a line to `llms.txt`. That file builds the website's sidebar.
3. Commit and push. The website updates within a minute or two.

To preview locally, open the folder in VS Code and use the **Live Server** extension. Opening `index.html` directly from disk won't load the pages.

See [CLAUDE.md](CLAUDE.md) for the documentation conventions.
