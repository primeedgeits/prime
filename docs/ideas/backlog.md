## Suggested by Claude (not reviewed)

Starting points suggested while setting up these docs. Accept, change or delete them.

| Idea | Why it might help |
|---|---|
| Emergency (panic) button | One press sends an alarm with the location and a video clip to the control room |
| Event-triggered video upload | Upload a short clip automatically when an alarm or harsh event happens, instead of streaming all the time |
| Driver fatigue and distraction alerts (DMS) | Uses a driver-facing camera; a common request from bus fleets |
| Harsh driving detection | Detect harsh braking, acceleration and cornering from an accelerometer and CAN data |
| Remote firmware updates (OTA) | Fix and improve devices in the field without visiting each bus |
| Geofencing and route deviation alerts | Alert when a bus leaves its route or enters a restricted area |
| Fuel monitoring | Fuel level and consumption from CAN, to spot theft or waste |
| Passenger counting | Count passengers with door cameras, giving operators ridership data |
